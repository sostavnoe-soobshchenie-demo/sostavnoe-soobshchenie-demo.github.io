Голосовой блок — детальный разбор

Уникальная фича
Голосовой блок с транскрипцией — редкость среди мессенджеров. Telegram, Slack, Teams — везде голос и текст разделены. Интеграция в multi-block баббл даёт уникальный UX: голос + контекст + файлы в одном сообщении.
🎙 Запись

Кнопка записи на тулбаре. Волновая анимация во время записи. Пауза / продолжить. Максимальная длительность (например, 10 мин).

Создаётся голосовой блок с waveform и длительностью.

🔊 Воспроизведение

Плеер: play/pause, seekbar, таймер. Скорость ×1 / ×1.5 / ×2. Waveform с выделением прослушанного участка.

Автопауза при скролле (опционально).

📝 Транскрипция

Текстовое представление голоса под плеером. Редактируемое — пользователь может поправить ошибки распознавания. Сворачивается (показать/скрыть).

При поиске по чату — находит и голосовые по транскрипции.

🔗 Комбинирование

Голосовой блок + текстовый блок в одном бабле = «Голос + расшифровка + комментарий + файлы». Полный контекст без отдельных сообщений.

Редактирование отправленного баббла

3 готово 6 важно 3 идеи
Контекст: Редактирование реализовано через edit-mode в Mode 13. Баббл открывается в редакторе с восстановленным состоянием блоков. Всё что работает при создании — доступно и при редактировании.
🔓
Вход в режим редактирования
✓ Готово

Долгое нажатие / контекстное меню на бабле → «Редактировать». Баббл открывается в Mode 13 редакторе.

ghostEditMsgId фиксирует какое сообщение редактируется. resolveInitialState восстанавливает блоки, изображения, файлы, лейблы из сохранённого состояния.

Критически важен порядок: resolveInitialState вызывается до transferGhost — иначе блоки слетают.

ghostEditMsgIdresolveInitialStatetransferGhost
💾
Сохранение изменений
✓ Готово

Enter / кнопка отправки → handleGhostSend в edit-режиме обновляет существующее сообщение по ghostEditMsgId.

Финальные блоки собираются: innerHTML каждого contenteditable → textHtml, фильтрация пустых блоков.

handleGhostSendСборка textHtmlФильтрация пустых
✖️
Отмена редактирования
✓ Готово

Кнопка «Отмена» / Escape → handleGhostCancel. Редактор очищается, ghostEditMsgId сбрасывается. Оригинальный баббл остаётся без изменений.

handleGhostCancelEscape

Сейчас: только добавить/удалить фото или файл. Нет возможности «заменить» конкретную картинку на другую — нужно удалить и добавить заново с потерей порядка.

Нужен: контекстный пункт «Заменить» на каждой картинке.

Идеи

👁
Live-preview при редактировании
◈ Идея

Пока редактируешь — другие участники видят «Максим редактирует сообщение…» (как «печатает»). Повышает ожидание обновлённого контента.

Typing indicator
⚡
Быстрое исправление опечаток
◈ Идея

Двойной клик по тексту в отправленном бабле сразу открывает inline-редактор без перехода в полный edit-mode. Для быстрых правок опечаток.

Inline editDouble-click
📊
Diff-подсветка для получателей
◈ Идея

После редактирования получатели видят изменённый баббл с подсветкой diff: добавленный текст — зелёным, удалённый — красным зачёркнутым. Как в Notion history.
